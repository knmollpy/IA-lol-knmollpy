# IA-lol-knmollpy
A client-side AI implementation: it integrates free APIs from Gemini, OpenRouter, and Groq, and the AI ​​can process text and files such as PNG, JPG/JPEG, WEBP, GIF, and HEIC/HEIF.
To set up the AI, you simply need to enter the API key and the URL where you obtained it; the AIs compatible with our interface are: https://aistudio.google.com/apikey / https://console.groq.com/keys  / https://openrouter.ai
### Features

* Advanced AI Chat
* AI Provider Selection
* Model Selection
* Automatic API Detection — manually add an API key and the URL where it was obtained
* Only models marked as free by the plugin
* Real-Time Response Streaming
* Local Chat History
* Usage Counter
* Image Support Detection
* Image Upload for Compatible Models
* Floating ✦ Button in the Bottom-Left Corner, Available Throughout the Client
* Quick Access via `Ctrl + K`
* Support for Multiple API Keys
* Quick Switching Between Providers and Models
* Conversation Export — download and save your chats for later
